# Sessions

The narrative of the last working session on the lab: what was done, what was
tried and failed, and what was left open. Read it before starting work.

A new session replaces the previous one. By then whatever mattered from it has
graduated - facts to `../cluster.yaml`, choices to `../decisions/`, failures
to the homelab repository's traps.yaml - and git keeps the rest. Work that
touched the house as a whole has its own note in the homelab repository's
docs/sessions/.
